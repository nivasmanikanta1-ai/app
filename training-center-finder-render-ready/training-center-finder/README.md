# Training Center Finder

Render-ready Node.js + Express application.

## Included data
- Kakinada: 33 centers
- Visakhapatnam: 12 centers
- Hyderabad: 10 centers
- Vijayawada: 19 centers

Total: 74 centers from the training-center data supplied for this project.

## Run locally
npm install
npm start

## Render
Build command:
npm install

Start command:
npm start

The server uses `process.env.PORT` and listens on `0.0.0.0`, so it is suitable for Render.

Optional environment variable:
SESSION_SECRET=change-this-to-a-long-random-value
